Description
A stunning, high-performance Clothes Shopping App built with Flutter that lets users browse, search, filter, and buy fashion items (men’s, women’s, kids, accessories).
Perfect showcase of production-ready Flutter architecture using Clean Architecture + MVVM + Bloc + Dio + Hive/GetStorage.
Works flawlessly on Android, iOS, and Web with buttery-smooth animations and responsive design.

## Features
Home: banners, new arrivals, best sellers, categories

Browse: Men/Women/Kids, Shoes, Bags, Accessories

Search + filters (price, size, color, brand, rating)

Product details: gallery, options, reviews, related items

Cart: add/remove, totals, coupons

Wishlist sync

User auth: login, orders, addresses

## Tech Stack & Architecture
Flutter + Dart
- Clean Architecture (Presentation / Domain / Data)
- Bloc (flutter_bloc) for state management
- Dio for API & networking
--GetIt + Injectable for dependency injection
- Retrofit for API generation
- JSON Serializable for models
- Shared Preferences for local storage
- Google Fonts, Cached Images, Carousel Slider
